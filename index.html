About

大会介绍

从「联接」走向「价值共创」，让贡献被看见，让价值被认可

建筑行业正从"规模红利"滑向"存量博弈"。数字化已取得显著进展，但更深层的命题亟待回答：联接之后，价值何往？ 2026云顶大会致力于推动产业从"联接"走向"价值共创"，让贡献被看见，让价值被认可，引导资源流向真正创造价值的环节。

大会主题

「从联接走向价值共创」—— 聚焦AI与建筑产业深度融合，探讨数字供应链、智慧劳务、AI大模型等实践成果，推动行业从价格战转向价值战。

大咖云集

邀请知名经济学家、行业专家学者及领军企业代表，围绕建筑产业新质生产力、智能建造、数字化转型及AI大模型应用等前沿议题展开深度分享。

活动形式

主题演讲 + 圆桌论坛 + 超级供需洽谈会 + 展览展示 + 颁奖仪式，全方位呈现建筑数智化前沿实践与生态共创成果。

核心议题

建筑产业新质生产力、智能建造、绿色建造、数字供应链、AI大模型应用、数字化转型及产业升级等热点方向。

参会指南

机场 / 高铁

  • 深圳宝安国际机场 → 展馆约15km（打车约30分钟）
  • 深圳北站 → 展馆约35km（地铁约50分钟）
  • 福田站 → 展馆约30km（地铁约45分钟）

自驾 / 打车

  • 导航至「深圳国际会展中心18号馆」
  • 广深沿江高速 → 国际会展中心出口
  • 展馆设有充足停车位（P1-P5停车场）

地铁出行

  • 地铁12号线 / 20号线 → 国展站 C出口
  • 步行约5分钟即可到达展馆
  • 运营时间：06:30 - 23:00
